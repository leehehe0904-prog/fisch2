# Fisch2 · 釣魚群島

一款用 **Three.js** 製作的 3D 釣魚遊戲（玩法類型參考 Roblox 的釣魚遊戲）。
甩竿、SHAKE、收線小遊戲、兩座島嶼、任務 NPC、魚商、開船、10 分鐘日夜循環。

## 怎麼開始玩

- **最簡單**：直接用 Chrome / Edge 打開 `index.html`（已經打包好 `dist/game.js`，不需要安裝任何東西）。
- 或是開啟 GitHub Pages（Settings → Pages → Branch: `main` / root），就能用網址遊玩。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| WASD / 方向鍵 | 移動（Shift 奔跑、空白鍵跳躍） |
| 按住滑鼠右鍵拖曳 / 滾輪 | 轉動視角 / 縮放 |
| 1 | 拿出 / 收起「新手釣竿」 |
| 2 ~ 9 | 拿起背包裡的魚（拿去給魚商賣） |
| 按住左鍵 → 放開 | 蓄力 → 甩竿（浮標要落在水裡） |
| 點擊 SHAKE | 魚上鉤時快速點擊畫面上的按鈕 |
| 按住左鍵 / 空白鍵 | 收線小遊戲：白條往右，放開往左，讓魚待在白條裡 |
| E | 與 NPC 對話、上船 / 下船 |
| B / N / H | 背包 / 魚類圖鑑 / 操作說明 |
| 開船 | W/S 前進倒退、A/D 轉向、Shift 全速 |

## 遊戲內容

### 釣魚
- 蓄力甩竿（力道條）→ 浮標拋物線飛行 → 落水水花、漣漪、浮標隨浪起伏、小魚試咬（浮標輕輕下沉）
- 魚上鉤：浮標被拉下去、頭上冒出「!」、水花與音效 → **SHAKE** 按鈕
- 收線小遊戲：白色控制條有慣性與反彈，魚會亂竄、突然衝刺；進度條滿了就釣上來
- 收線時釣竿會彎曲晃動、捲線器轉動、魚在水面掙扎濺起水花、水下有魚影
- 釣上來：魚從水裡飛出、角色雙手把魚舉過頭頂、稀有魚有閃光特效
- 畫面下方顯示 **魚名（重量）**、稀有度、價值，第一次釣到會有 **NEW!**
- 完美收線（魚從沒離開白條）價值 +10%

### 新手釣竿
| 屬性 | 數值 | 說明 |
| --- | --- | --- |
| 上鉤速度 | 25% | 100% = 一甩竿就上鉤 |
| 運氣 | 50% | 提高稀有魚的出現機率 |
| 控制力 | 0.1 | 收線小遊戲的白條變寬 |
| 復原力 | 35% | 魚不在白條內時，進度掉得比較慢、魚也比較不會亂竄 |
| 最大重量 | 5,000 kg | 超過的魚收線進度非常緩慢 |

### 魚
- 37 種魚 / 垃圾，8 個稀有度：垃圾、普通、罕見、不尋常、稀有、傳說、神話、異界
- 4 個釣點：noob Island 海岸、normal Island 海岸、normal Island 池塘（淡水）、外海
- 部分魚只在白天或晚上出現；有「巨大 / 閃亮 / 白化 / 迷你」變異
- 圖鑑記錄捕獲次數與最重紀錄

### 島嶼
- **noob Island**：新手島。廣場、營火、釣具店、魚商攤位、燈塔、長碼頭、椰子樹沙灘
- **normal Island**：海港漁村。風車、餐廳、旅館、漁會、淡水池塘、松樹山丘、雙碼頭
- 進入不同島嶼（或外海）時，畫面正上方會彈出島嶼名字

### NPC 與任務
- 新手導師・阿凱（完整教學 + 新手任務）、魚商・老陳 / 老王（賣手上的魚 / 全部賣掉）
- 釣具店・小美、船匠・阿木 / 大石（叫船）、碼頭漁夫・阿海、老漁夫・德叔、主廚・安娜、研究員・林博士
- 7 個任務，有任務追蹤欄和目標指示箭頭

### 世界
- 10 分鐘一次日夜循環（日出、黃昏、星空、月亮），晚上路燈、窗戶、燈塔會亮
- 自製水面著色器：波浪、菲涅耳反射、太陽/月光高光、岸邊泡沫、淺水透明、互動漣漪
- 海鷗、雲、螢火蟲、跳出水面的魚、營火、全部音效即時合成（不需要音檔）
- 自動存檔（localStorage）

## 開發

```bash
npm install
npm run build   # 輸出 dist/game.js
npm run dev     # 監看模式 + 本機伺服器
```

原始碼在 `src/`：`world/`（地形、水、天空、島嶼、船）、`fishing/`（釣竿、魚、小遊戲）、`npc/`（對話、任務）、`player/`、`ui/`、`audio/`。
